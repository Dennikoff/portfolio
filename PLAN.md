# План реализации — Denis Kharke Portfolio (тёмный дизайн)

Исходники (ТЗ, референс, портрет) лежат в [исходники/](исходники/). Здесь — только план того, что **мы разрабатываем**. Детали стека, токенов и структуры — в [CLAUDE.md](CLAUDE.md).

**Принцип:** не реализуем всё сразу. Каждая фаза = собираемое, проверяемое состояние. Статический layout стабилизируем ДО навешивания сложных анимаций, чтобы не переделывать magnet/стекинг/marquee под меняющуюся вёрстку.

### Фаза 0 — Каркас проекта
- `npm init astro` (static, TS strict), Tailwind v4 через `@tailwindcss/vite`, `@import "tailwindcss"`.
- `global.css`: ресет, `#0C0C0C` на html/body/обёртке, `.hero-heading`, `selection`, self-host шрифтов (нужные веса + `unicode-range`).
- `Base.astro` + пустой `index.astro`. Установить `motion`, `lenis`.
- **Готово, когда:** `npm run build` и `dev` проходят, страница на `#0C0C0C` с правильными шрифтами.

### Фаза 1 — i18n-каркас + словари
- `i18n/ru.ts`, `en.ts` (одинаковые ключи по схеме §3 ТЗ), `utils.ts`. Роут `/en/`, `<html lang>`, `hreflang`.
- Переключатель RU|EN в navbar (localStorage + редирект `/`→`/en/`).
- Тексты переносим построчно из `ru`/`en` объектов референса (см. CLAUDE.md → «Источники контента»). Соцсети — из §4.7 ТЗ.
- **Готово, когда:** обе локали рендерятся, переключатель работает.

### Фаза 2 — Статический layout всех секций (без JS-анимаций)
- Собрать Nav, Hero, Marquee, About, Pricing, Projects, Process, Contact — верная разметка, токены, респонсив, геометрия перекрытия секций. Картинки — плейсхолдеры с размерами.
- Стекинг/marquee/magnet пока статичны (карточки просто в потоке).
- **Готово, когда:** страница визуально целостна на desktop/mobile, семантика и контраст на месте.

### Фаза 3 — Базовые компоненты + появление
- `ContactButton`, `GhostButton`, `NumberedItem`.
- `FadeIn` + `fade.ts` (`inView`, одноразово, reduced-motion → конечное состояние).
- **Готово, когда:** секции плавно проявляются на скролле, reduced-motion уважается.

### Фаза 4 — Продвинутая интерактивность
- `lenis.ts` (smooth scroll) · `magnet.ts` (портрет) · `marquee.ts` (две ленты по скроллу, утроенный массив, `{passive:true}`+rAF) · `stack.ts` (стекинг карточек, на мобиле выключить) · `animated-text.ts` (посимвольно).
- Свести скролл-эффекты к одному rAF-циклу.
- **Готово, когда:** все эффекты работают и корректно отключаются при reduced-motion / `hover:none`.

### Фаза 5 — Ассеты + перформанс/доступность
- Реальные ассеты (WebP): портрет из `исходники/assets/photo.PNG` → `public/images/photo.png`. Скриншоты проектов (5×3) и плитки marquee (10–12) — **ещё нужны от заказчика**.
- Оптимизация, замер Lighthouse mobile, доведение до 95+.
- `content-visibility`, финальная проверка семантики/alt/тач-таргетов/AA-контраста.
- **Готово, когда:** Lighthouse ≥95 mobile, чек-лист §7 ТЗ закрыт.
